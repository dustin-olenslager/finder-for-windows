Annotations — the parts a wireframe must state

  • Purpose: <the decision this screen settles>
  • Screen: <what it is, and which spec user stories it serves>
  • State shown: <which state, and why that one>
  • Deliberately absent: real copy, brand colour, imagery, motion — plus anything else
  • Not wired: nothing is clickable; the interactions are listed below, not built
  • Interactions to design against: <what the reviewer should judge>
