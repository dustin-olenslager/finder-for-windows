finder-for-windows — 4 decisions

Tap an option in each group. Your picks are written to docs/agents/decisions/0001-open-decisions.md — they stay here until you change them.
1 · What kind of Finder clone?
Windows has no cross-application metadata store, so a literal copy is impossible. This picks the target.
2 · Which view opens by default on a new folder?
Every folder still remembers its own last-used view — this is only the first-ever default.
3 · How much goes in v1?
Search is the part that scales the effort — a real content index is a project of its own.
4 · Where do your tags live?
Finder stores tags in the filesystem itself. Windows has no equivalent, so this is a real choice with a real trade-off.
